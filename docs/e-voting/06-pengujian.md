## Integrasi SQL dan keamanan

Jalankan integration pada DB **terisolasi**, bukan Neon berisi master siswa. Validasi FK composite, duplicate Student, deferred mode/rights/order, append-only Ballot/audit, freeze dan rollback cleanup. Raw SQL invalid harus gagal juga; tes service saja tidak membuktikan trigger. Periksa orphan, rowcounts, grants dan migration drift; Prisma validate/generate tidak mengganti test SQL.

RBAC negatif setiap endpoint baru/berubah: anonymous, PIN, alumni, guru akun internal tanpa izin, izin dicabut saat sesi aktif, akun nonaktif, superadmin dengan revoked capability. Mutasi tanpa Origin/CSRF/salah-session/expired/replay, wrong contenttype/oversize/unknownfield, SQL injection kode/cursor, XSS nama/visi/misi/URL. CSRF/JSON error aman tanpa stack/secret. Rate limiter lintas instance dan reauth akun caller, bukan body actor.

Uji lock memakai barrier nyata untuk race Student candidate, master attach/delete, dual revision, vote/schedule/close/reset/activity/logout/extension. Jangan hanya mock $transaction. Profil tiga sesi dan p95/error pada jaringan representatif Neon; timeout awal vote5s/admin-close10s bukan SLA terukur. Tidak perlu menguji99 login bersama karena slot3 tetap.
